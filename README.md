# CS336 Learning Lab

Stanford **CS336: Language Modeling from Scratch**의 공개 자료를 바탕으로, 언어 모델을 구성하는 원리를 직접 구현·실험하고 설명하기 위한 개인 공개학습 저장소입니다.

**현재 상태: 준비 단계.** 저장소 구조, 기록 양식, 첫 독립 실험 계획을 마련했습니다. 강의 수강 완료, 과제 통과, 모델 구현·학습 결과는 아직 없습니다. 초기 문서와 구조는 Codex의 도움으로 작성했으며, 이를 개인의 학습 성과로 세지 않습니다.

## 무엇을 남기는가

한 가지 질문을 개념 노트 → 직접 구현 → 비교 실험 → 결과와 한계로 연결합니다. 실패한 접근, 예상과 다른 결과, 다음에 확인할 질문도 기록합니다. AI 엔지니어링에서 쓰는 도구를 언어 모델의 내부 동작과 연결해 이해하고, 다른 사람에게 설명할 수 있는 기록을 지향합니다.

이 저장소는 **강의 정답 복제물이나 공식 과제 해설이 아닙니다.** Stanford와의 소속·제휴·공식 수강 인증을 의미하지 않습니다. 강의 자료와 과제 원본은 링크로 참조합니다. 공식 과제 풀이와 제출용 코드를 이 저장소에 올리지 않으며, 공개 구현은 별도로 설계한 작은 독립 실험으로 구성합니다.

## 시작하기

1. [학습 경로](docs/learning-plan.md)와 [출처·공개 원칙](docs/learning-policy.md)을 읽습니다.
2. [첫 질문 노트](notes/0001-text-representation.md)에 직접 이해한 내용과 미해결 질문을 씁니다.
3. [첫 실험 계획](experiments/0001-utf8-representation/README.md)에 따라 최소 구현을 작성하고 입력과 조건을 고정합니다.
4. 실행한 뒤 결과 파일을 `results/0001-utf8-representation/`에 저장하고 노트·실험 문서에 연결합니다.

문서를 읽고 기록하는 데 설치는 필요하지 않습니다. 실행할 구현과 패키지 의존성(dependency)은 아직 없으며, 필요한 도구는 해당 실험에서 비교·선택한 뒤 버전과 재현 명령을 기록합니다.

## 기록 규칙

| 상태 | 의미 |
|---|---|
| `PLANNED` | 질문과 실험 계획만 작성 |
| `IN_PROGRESS` | 읽기·구현·실행 중. 결론 미확정 |
| `EXECUTED` | 실행 결과·입력·환경·코드 버전 기록 완료 |
| `REPRODUCED` | 동일 조건으로 별도 재실행하고 결과 일치 여부를 기록 |

모든 노트·실험에는 동일한 식별자(ID)를 사용합니다. 새 기록은 `templates/`를 복사해 `0002-<topic>`처럼 추가하고 각 목록에 링크를 남깁니다. 빈 양식이나 계획을 완료한 결과로 표시하지 않습니다.

## 강의 기준과 출처

기준 판본은 자료를 고정해 추적하기 쉬운 [Spring 2025 공식 아카이브](https://cs336.stanford.edu/spring2025/)입니다. 다른 판본을 참고하면 연도와 링크를 개별 노트에 적습니다. [현재 강의 사이트](https://cs336.stanford.edu/)의 내용과 혼합하지 않습니다.

강의의 AI 도구·기존 코드 관련 규정을 참고하며, AI로 과제 정답을 생성하지 않습니다. 공개 가능한 독립 기록의 구체적인 기준은 [학습·공개 원칙](docs/learning-policy.md)에 정리했습니다.
