# 0001 — 파일 중심의 공개학습 구조

- 상태: 채택
- 날짜: 2026-10-05
- 기준: 기록 지속성, 재현성(reproducibility), 관리 부담, 강의 정답과의 구분

| 후보 | 기록 지속성 | 재현성 | 관리 부담 | 강의 정답과 구분 |
|---|---|---|---|---|
| 하나의 README | 처음에는 간단하나 누적 탐색이 어려움 | 실행 조건이 본문에 섞임 | 낮음 | 별도 규칙 필요 |
| Markdown + notes/experiments/src/results | 식별자로 설명·구현·결과 연결 | 조건과 결과를 독립 보존 | 낮음 | 자체 질문 단위로 기록 가능 |
| 문서 사이트 + 외부 실험 추적 서비스 | 검색·시각화 확장에 유리 | 서비스 설정에 좌우됨 | 초기 설정·배포·계정 필요 | 별도 규칙 필요 |

두 번째 방식을 선택한다. 새 서비스, 데이터베이스, 추적 데몬(daemon), 패키지 의존성(dependency)은 도입하지 않는다. 초기 결과 디렉터리에는 안내만 두며 빈 결과를 실적으로 표시하지 않는다.

강의 기준 판본도 비교했다.

| 후보 | 추적성 | 최신성 | 선택 |
|---|---|---|---|
| Spring 2025 아카이브 | 명시된 판본으로 안정적 참조 가능 | 최신 변경은 별도 확인 필요 | 기본 학습 자료 |
| 현재 강의 사이트 | 갱신되는 자료는 기록 시점 필요 | 현재 내용 확인에 유리 | 보충 자료 |

기준 판본은 2025로 고정하고 다른 판본은 개별 기록에서 명시한다. 이는 학습 시작을 위한 기본 선택이며 수강 이력에 대한 주장이 아니다.

재평가 조건: 기록량 때문에 링크 탐색이 어려워지거나 다수 실험의 조건 비교가 반복적으로 필요해질 때 사이트·추적 도구를 다시 비교한다. 구현 단계에서 계산 라이브러리가 필요해지면 별도 ADR에서 후보를 비교한다.
