# 출처·학습·공개 원칙

## 공식 자료

- [CS336 Spring 2025](https://cs336.stanford.edu/spring2025/) — 기준 판본과 Honor code 확인. 확인일: 2026-10-05.
- [현재 CS336](https://cs336.stanford.edu/) — 다른 판본의 진입점.

2025 강의 규정은 낮은 수준의 프로그래밍 질문과 높은 수준의 개념 질문에 AI 도구를 허용하지만, 문제를 직접 풀게 하는 사용을 금지합니다. 허용된 경우 외에는 기존 구현을 보지 않도록 안내합니다. 이는 공식 페이지의 요약이며, 개별 과제를 수행할 때에는 그 판본의 원문 규정을 다시 확인합니다.

## 이 저장소의 공개 범위

- 직접 작성한 개념 설명, 개인 질문, 자체 제작 입력, 공식 제출물과 구분되는 독립 실험을 남깁니다.
- 강의 슬라이드·과제 원본·정답·채점기(grader)·다른 사람의 구현은 복제하지 않습니다. 필요한 경우 원문을 링크합니다.
- 공식 과제의 풀이·제출용 구현은 이 공개 저장소의 범위에서 제외합니다. 이는 이 저장소가 선택한 공개 원칙이며, 강의가 모든 독립 실험 공개를 금지한다고 해석하지 않습니다.
- 참고한 설명·논문·코드는 출처, 판본, 참고한 범위, 사용 조건을 기록합니다.
- 데이터셋(dataset)·모델 가중치(weight)는 기본적으로 올리지 않고, 사용 권한과 재현 가능한 획득 경로를 기록합니다.
- API 키, 개인정보, 수업 참여자 정보, 고객 문서는 올리지 않습니다.

## 작성과 검증

초기 저장소 구조와 문서 양식은 Codex가 작성했습니다. 실제 학습 노트의 결론·개인 경험을 대신 작성하거나 과제 구현을 생성하지 않았습니다. 이후 AI 도움을 받으면 도움의 범위와 직접 확인한 부분을 기록합니다.

`EXECUTED`에는 코드 버전, 실행 명령, 입력 출처, 환경, 실제 결과가 필요합니다. `REPRODUCED`에는 별도 재실행의 기록이 추가로 필요합니다. 예측과 빈 양식은 측정 결과로 간주하지 않습니다.
