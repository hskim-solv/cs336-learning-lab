## 한 번의 학습 기록

1. 공식 자료의 판본·제목·링크와 읽은 범위를 기록합니다.
2. 자료를 닫고 핵심 개념을 자신의 말로 설명합니다.
3. 독립적인 작은 질문과 입력을 설계합니다.
4. 구현의 정확성을 확인한 뒤 비교 조건을 고정해 실행합니다.
5. 원시 측정값, 요약, 해석을 구분하고 코드 커밋(commit)을 기록합니다.
6. 노트에 예상과 달랐던 점, 교육용 예제, 다음 질문을 추가합니다.
